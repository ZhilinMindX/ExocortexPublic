# B2 References — The 36 Stratagems, Distilled Structure

Load this when: a question needs the stratagem taxonomy, a stratagem's number,

(B2, 179 chunks). Distills STRUCTURE, not summary — B2's prose stays in chunks.

## Provenance & authorship (grounded)

- Anonymous compilation (CLAIM-003). B2 p.4–5: first recorded mention in the
  Nan Qi Shi ("Of the 36 stratagems of Master Tan, running away is the best");
  no evidence for or against General Tan Daoji (d. 436) as author.
- All modern versions descend from a tattered book found ~1940s; reprinted
  Beijing 1979 (B2 p.5). Likely Qing-era editorial collection of much older
  idioms (e.g. #2 named for an event of 352 BC, attributed to Sun Bin).
- Domain: politics, diplomacy, espionage, psychological warfare — where Sun
  Tzu treats organization and battle, this treats deception (B2 p.4).

## The six families (six stratagems each)

| Family | Numbers | Logic |
|---|---|---|
| I. Stratagems for winning | 1–6 | act from strength, conceal the true move |
| II. Stratagems for confrontation | 7–12 | manufacture advantage mid-contact |
| III. Stratagems for attack | 13–18 | probe, decoy, decapitate |
| IV. Stratagems for confusion | 19–24 | exploit disorder; create it if absent |
| V. Stratagems for gaining ground | 25–30 | convert position into control |
| VI. Stratagems for desperate straits | 31–36 | survive defeat; exit preserves all |
