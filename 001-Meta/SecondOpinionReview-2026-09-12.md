# Second Opinion Review — Differential Adjudication

An external reviewer analyzed the Exocortex and produced a six-part
assessment. This annex records the Council-side verdicts. The reviewer's
component map was accurate but stale (110 books/27,628 chunks; actual
125/31,357) and several "gaps" it identified were already closed —
recorded here so the external record is corrected.

## A. Already built (reviewer gaps that are not gaps)

1. Tiered routing / dispatcher (3–7 voices per query) — EXISTS:
   CouncilVoting v1.1 sensor-routed panels (5–7 voices by retrieval rank +
   1 callosum seat + 1 Rotating Contrarian). The full 52 never convene.
2. Human-in-the-loop crystallization gates — EXISTS by constitution:
   the Architect ratifies all doctrine.
3. Reflection readership — PARTIAL: voice_health() telemetry and Claim
   Ledger review dates exist; periodic crystallization does NOT (see B.1).

## B. Adopted (queued as work items)

1. **Knowledge Crystallization Cycle** — periodic Trajectory Bank review
   with formal ops: generalize / contradict / refine / retire; dual-
   workspace made explicit (chamber vs. ledgers). The mechanism that
   produced F-001/F-002 becomes a scheduled rite.
2. **Programmatic constitutional checks** — LAW.md is currently a
   prompted constitution; build validators (citation presence, Kent-band
   format, [INFERRED] enforcement) as a Coding Cluster module. The
   reviewer's sharpest point.
3. **Doctrine provenance + conflict detection** — every F-series entry
   cites parent trajectories/claims; new entries are checked against
   existing doctrine before ratification.
4. **Persona drift re-anchoring** — periodic StyleSheet anchor
   re-injection in long sessions.
5. **Hybrid retrieval** — BM25 + embeddings with reciprocal rank fusion
   (Khoj bi-encoder pattern). Supersedes the standing "embeddings" note.

## C. Reframes (challenge answered, design kept)

1. "Is 52 voices right?" — they never convene together; the 52 are a
   casting bench, panels are 5–7. Challenge answered by v1.1.
2. "Is bicameralism cognitively valid?" — it is an architecture of
   OBLIGATION (evidence lens + resemblance lens), not neuroscience.
   Falsifiable via output quality; logged as a fair F-series test.
3. "5-voice MVC" — rejected as identity loss: generic roles are what
   every other system does; grounded named doppelgangers ARE the
   differentiator. The Council is the product, not a feature.

## D. Rejected

1. Vault transparency-gap concern — handled by owned-work protocol
   (cite by ID, short quotes only; vault plaintext never in the public
   pipeline by construction).
2. WeClone-style fine-tuning of 52 voices — cost-flagged by the reviewer
   itself; StyleSheet + RAG grounding achieves fidelity. Adapter notes
   remain the future option.
